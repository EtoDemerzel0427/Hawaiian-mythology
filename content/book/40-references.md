!!! tldr
    - 这是 Beckwith 原书的参考文献目录，共约一百六十种著作和十几个缩写。书中脚注都用简称引用，要查出处，就要回到这份目录。
    - 带星号（\*）的是夏威夷材料，带剑号（†）的兼含夏威夷与南太平洋材料，其余是南太平洋、美拉尼西亚、东南亚等地的比较材料。
    - 本页每条保留原书的作者名与书名，后附中文说明；出版信息照原书。没有把握的事实，一概不写。
    - 若只想继续读几部书：Fornander 的《夏威夷古物与民俗集》、Malo 的《夏威夷古俗》、Kamakau 的报纸连载、N. B. Emerson 的《草裙舞圣歌》、Beckwith 自己的《拉伊埃伊卡瓦伊》译注本。

!!! source "脚注里的缩写怎么读"

    | For. Pol. Race | Fornander, *An Account of the Polynesian Race* | 福南德《波利尼西亚种族志》 |

    | RBAE 33 | 美国民族学局第 33 号年度报告 | |
    | JAFL, TNZI, MPS, ZE | 美国民俗学杂志、新西兰学会会刊、波利尼西亚学会专刊、德国《民族学杂志》 | |

    没有书名、只有人名和页码的注（如“Gill, 77-79”“Henry, 421-428”“Hocart, 155-159”），指这位作者在下列目录中唯一的一部书；同一作者有几部书时，Beckwith 用书名的简称区分。

!!! source "延伸阅读：从哪里读起"
    **夏威夷本土作者的记录**是一切的基础：马洛（Malo）的《夏威夷古俗》（1903 年英译；1951 年有毕晓普博物馆重印本）、卡马考（Kamakau）的报纸连载（后来英译为 *Ruling Chiefs of Hawaii*、*Ka Po‘e Kahiko* 等书）、凯佩利诺（Kepelino）的传统记录（Beckwith 1932 年译注）。福南德的《夏威夷古物与民俗集》收录了大量夏威夷语原文与英译，是本书引用最多的资料。

    **吟诵与草裙舞**：N. B. Emerson 的《草裙舞圣歌》（1909）与《佩蕾与希伊亚卡》（1915）、Helen Roberts 的《古代夏威夷音乐》（1926）。

    **传说集**：Thrum 与 Westervelt 的几部集子流传最广、最易读到，但都经过英文的文学改写，与夏威夷语原文有距离。Laura Green 与 Mary Kawena Pukui 的集子附有夏威夷语原文，更为可靠。

    **南太平洋比较**：毕晓普博物馆的 *Bulletin* 系列是 1920–30 年代各群岛民族志的主体，Buck、Handy、Gifford、Henry、Stimson 等人的著作都在其中。毛利材料可从 Grey 与 Best 入手，塔希提材料从 Henry 的《古代塔希提》入手。

    1940 年以后最重要的补充包括：Pukui 与 Elbert 的《夏威夷语词典》（1957）、Pukui、Elbert 与 Mookini 的《夏威夷地名》、Beckwith 本人的《库穆利波》英译（1951）。毕晓普博物馆的许多出版物今天可在其网站或公共图书馆中查阅，福南德、马洛、Thrum、Westervelt 等公有领域的书也有数字化的全文。另见[[essays/sources]]。
