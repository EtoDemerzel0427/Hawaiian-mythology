!!! tldr
    - 前几章已经说明《库穆利波》是夏威夷人公认的开端传统，并与南方诸群岛同出一源。本章更进一步：在别的波利尼西亚群岛，类似的谱系祷歌是在酋长之子诞生的仪式上吟诵的。
    - 证据有两处：Handy 记录的马克萨斯“长子降生”大吟诵节（*vavana* 与 *pu‘e* 两类颂歌），以及 Percy Smith 发表的两首土阿莫土“高等酋长诞生时所唱”的颂歌。
    - Beckwith 由此推论：这类颂歌关心的不是“世界怎样形成”的思辨，而是颂歌对新生孩子的直接效力。新生的高等酋长本身就是神，吟诵谱系是提醒众祖神对这个新后裔负起责任。
    - 这一章是第 28 章“结语”的直接铺垫。

¶1 前面几章已经举出证据，说明《库穆利波》颂歌被夏威夷人公认为本民族真正的开端传统，而南方诸群岛相应的传统也证明，它的作者取材于波利尼西亚共同的源头。我们还可以更进一步，说明在别的波利尼西亚群岛，类似的谱系祷歌，即把家族血脉一直追溯到众神、并与地上生命的开端相连的颂歌，在酋长之子诞生时举行的仪式中也有一席之地。

!!! note "“前面几章”指什么"
    指第三部的前两章：[[ku:25]]讨论夏威夷本土各家对创世的解说（Kukahi、Kepelino、Malo 等），[[ku:26]]把《库穆利波》与毛利、塔希提、土阿莫土、芒艾亚等地的创世传说相比较。本章在此基础上转向一个新问题：这类颂歌在仪式中是做什么用的。

¶2 关于这类仪式，迄今只有两处资料：一是 Handy 报告的马克萨斯（Marquesas）材料，二是 Percy Smith 报告的土阿莫土（Tuamotu）材料。[^1]Handy 说，马克萨斯人会举行“盛大的吟诵节……一边吟诵，一边举行相应的仪式……由家族为各种目的而举办；如果是酋长家族，则由整个部落举办”。其中一个场合就是“头生继承人的降临”。仪式的“核心”是吟诵创世颂歌，即 *vavana* 与 *pu‘e*。背诵谱系也是这一场合的内容之一，由家族各个支系的代表参加。先由一位吟诵者开头。“他吟到颂歌的某一处便停下，由家族某一支系的代表接着背诵本支的谱系。”如此轮流，直到各个支系都有人代表为止。

!!! people "Handy 与 Percy Smith"
    **E. S. Craighill Handy**（1892–1980），美国民族学家，1920–1921 年随毕晓普博物馆的考察队在马克萨斯群岛做田野调查，此处所引的《马克萨斯本土文化》（*The Native Culture in the Marquesas*，毕晓普博物馆 *Bulletin 9*，1923）就是这次调查的成果。他后来长期研究夏威夷，与 Mary Kawena Pukui 合著有关于夏威夷农耕和家族制度的书（见[[ku-references]]）。

    **S. Percy Smith**（1840–1922），新西兰测量总监，1892 年与人合创波利尼西亚学会（Polynesian Society），长期主编《波利尼西亚学会杂志》（*JPS*）。他热衷于从各岛谱系推算波利尼西亚人的迁徙年代，这一方法今天已不被接受，但他在 *JPS* 上刊布的大量原始文本仍有价值。

¶3 讲 ‘Atea（即夏威夷的瓦凯亚〔Wakea〕）使 One-u‘i（沙之女）受孕的创世故事，是 *pu‘e* 颂歌的主题。据说这些颂歌禁止（kapu）传授给女人；吟诵时，女人也不得在场听。*vavana* 讲的则是孩子的成长，吟诵时谁都可以听。下面引 Handy 对其内容的概括：

!!! compare "‘Atea 与瓦凯亚"
    马克萨斯语的 ‘Atea（Ātea）与夏威夷语的 Wākea 是同一个名字：东波利尼西亚各语言之间常见这类语音对应。在马克萨斯，‘Atea 是天（或光明）的化身，与大地之母一类的女性配偶结合生出万物；在夏威夷，瓦凯亚与帕帕（Papa）是夏威夷人与诸岛的始祖，见[[ku:21]]和第一本书[[ch:20]]。Beckwith 照 Handy 的说法，称 One-u‘i 为“沙之女”；one 在马克萨斯语和夏威夷语里都是“沙、土”。

¶4 [*vavana* 的]词句把孩子的受孕、诞生、成长等等一一重述，并把这些与众神从上层（*papa una*）和下层（*papa a‘o*）神话般的诞生联系起来。在后面的部分，颂歌讲到为孩子制作饰物、武器和用具，讲到他的独木舟、他的神圣居所，以及与他有关的种种习俗，如沐浴、制作树皮布等等……并把这一切都与关于众神和古老土地的神话典故连在一起。颂歌有些地方召请各位神祇前来助成仪式。这首颂歌非常长，超过一万个词。其中有大量反复出现的短语，有些毫无意义。……通篇交织着与孩子有关的事件的叙述、神话典故，以及这些无意义的短语。

!!! language "papa una 与 papa a‘o"
    马克萨斯语的 papa 与夏威夷语、毛利语的 papa 同源，本义是“平面、层”，也是大地之母帕帕（Papa）的名字。马克萨斯人把宇宙想象为上下相叠的若干“层”，众神从上层与下层诞生。Handy 所说的“无意义的短语”，在今天的研究者看来未必真的无意义：许多波利尼西亚祷词中保留着古词、秘传语和仪式性的重叠，外人和后人往往已不能解。

¶5 没有理由认为，夏威夷的开端颂歌在内容和意义上会完全依照马克萨斯颂歌的模式。事实上，马克萨斯人自己的这类颂歌也互有不同。Handy 说：“每个部落都有自己的一套神圣颂歌。”尽管如此，他对风格的描述与夏威夷颂歌丝毫不差；他对内容的描述，则为 Pokini Robinson 的看法提供了有力的论据：她认为《库穆利波》是以一个孩子从出生到成年的成长过程为蓝本的。马克萨斯颂歌中还有一部分“重述世界成长的基本阶段”：它把各种植物列为 One-u‘i 受 ‘Atea 之孕以后的“所生”，以便为孩子出生后的种种活动提供所需的材料。这或许可以为理解夏威夷《库穆利波》所列的海中与陆上的种种诞生提供一条线索。在马克萨斯颂歌中，人们召请“各种材料之母”提供材料，为最初的父母 ‘Atea 与 One-u‘i 建造房屋。颂歌在这里引入“海中各种各样的鱼”作为“‘Atea 的妻子”，Handy 对此感到困惑，但其意义想必也与此相似。这样，众神中对人类友善的那些，被表现为在陆上和海中为那个将成为他们直系后裔的孩子预备生计；而部落中每个家族的头生子，都借着吟诵 *vavana* 与 *pu‘e*，宣称自己是这个孩子一代代传下来的后裔。

!!! culture "Pokini Robinson 的读法"
    Pokini Robinson 是 Beckwith 的夏威夷报道人，熟悉酋长圈子里的吟诵传统。她认为颂歌前七个 wā（夜的时代）象征一位神圣的禁忌酋长从婴儿到少年的成长，第八 wā 起的“昼”则是理性之光的破晓，见[[ku:7#p15]]与[[ku:8#p26]]。马克萨斯的 *vavana* 把孩子的成长与万物的生成交织在一起吟诵，正好为这种读法提供了一个仪式上的实例。参见[[essays/kumulipo]]。

¶6 在 Handy 报告马克萨斯仪式之前约二十年，S. Percy Smith 已在《波利尼西亚学会杂志》上发表了两首土阿莫土颂歌的原文与译文，这两首颂歌是“在一位高等酋长诞生时唱的”。据我所知，这一地区的学者至今没有注意到它们。译文出自“一位塔希提绅士”之手，Smith 本人依照毛利语的用法作了一些修订；他在原文中发现了“许多与毛利 *karakia* 完全相同的短语”。可惜他没有把这些相同之处引出来。他还把颂歌中 Tane 神的显要地位、以及 Tangaroa 所受的轻视，也归因于毛利的影响。关于颂歌的大致内容，他写道：“这类作品照例措辞隐晦，它们追溯到万物之始，然后把新生儿的来历追溯到众神，再经由祖先一直追溯到那次迁徙。”

!!! compare "Tane、Tangaroa 与 karakia"
    Tane 与 Tangaroa 是毛利语的形式，相当于夏威夷的卡内（Kane）与卡纳洛亚（Kanaloa）。在毛利神话中，Tane 是森林与人类之神，把天父 Rangi 与地母 Papa 推开的正是他；在塔希提与土阿莫土的许多传统里，Ta‘aroa / Tangaroa 则是至高的创造神。所以 Smith 觉得一首土阿莫土颂歌以 Tane 为主、Tangaroa 退居其次，像是毛利的口吻。*karakia* 是毛利语的“祷词、咒语”，泛指一切仪式性的吟诵祷文。

¶7 这两首颂歌不仅在内容上，在形式和精神上也都与《库穆利波》相像。同样强调对立面，同样充满神话典故，同样重视叠句。第一首颂歌以 *tumu* 一词为基调：吟诵者迎接作为万物“根源”“起因”“本源”的生育之偶 Tane 与 Hine；欢呼彩虹，那是酋长诞生的征兆；并以 Rongo 之名祝新生儿长寿。这个名字与库克船长在夏威夷被奉为洛诺（Lono）神时仪式上所呼的“Rono”完全相同；考虑到《库穆利波》是献给“Makahiki 的洛诺”的，这一点很耐人寻味。第二节里，“思念”（*manava*）向各个方向伸展，全都对新生的“Rongo”有利。消息传来，为酋长 Rongo 击起了鼓。接着宣告要寻找那“起因”、那“本源”，结果发现孩子是从“茎干”、从 ‘Atea、Fakahotu 与 Rongo 撒下的“种子”所生；原文中反复出现的 *tumu* 一词，在英译中被译成了种种不同的意思。随后是一联对句，说出一句格言，与 Kukahi 所说神与人各有其世界的区分相合：

!!! language "tumu、Rongo 与 Rono"
    *tumu* 在许多波利尼西亚语言中都是“树根、树干、根源、起因”，夏威夷语的对应词就是 *kumu*，即 Kumulipo 一名的前半（见[[essays/kumulipo]]）。Rongo（毛利、土阿莫土）、Ro‘o（塔希提）与夏威夷的 Lono 也是同一个名字，夏威夷语以 l 对应其他方言的 r、以 n 对应 ng（同理，Tangaroa 对应 Kanaloa）。库克的船员记下的“Orono”“Rono”，就是 Lono 在他们耳中的样子。

!!! story "库克与“Makahiki 的洛诺”"
    1779 年 1 月，库克船长的船队在 Makahiki 节期到达夏威夷岛的凯阿拉凯夸湾，祭司在 Hikiau 神庙中以洛诺的名义向他致敬。《库穆利波》据说就是为一位出生在 Makahiki 节期、因此得名 Lono-i-ka-makahiki（“在 Makahiki 中的洛诺”）的王子而作，相传库克受礼时祭司也吟诵了这首颂歌。见[[ku:4]]、[[ku:5]]，以及[[essays/cook-and-lono]]；Makahiki 见[[g:makahiki|丰收节]]。

¶8
> 神[*no te atua*]的道路[*te ara*]在下面[*ki te po*]；
> 人[*te tangata*]的道路在上面[*ki te ao*]。

!!! language "te po 与 te ao"
    土阿莫土语的 *te* 是定冠词，相当于夏威夷语的 *ka/ke*；*ara*（路）即夏威夷语 *ala*，*atua*（神）即 *akua*，*tangata*（人）即 *kanaka*。*po* 与 *ao* 就是《库穆利波》全诗的骨架：前七个 wā 属于 [[g:po|pō]]（夜，神灵的世界），从第八 wā 起进入 [[g:ao|ao]]（昼，人的世界）。Kukahi 对 pō 与 ao 的解说见[[ku:25#p7]]。

¶9 接下来是一连串三行一节的诗节，每节都以一句叠句作结，宣告小神（*Vaitu*）与人的“成长”（*tupuranga*）。[^t1]

¶10 再往下几段像诗节一样的词句，由在场众人的代表轮流吟诵。译者解释说：“……国王的臣民为国王喜得子嗣或其他大事前去道贺时，聚集在宫廷，即 *mahora*，开始致辞之前，即将发言的人先用脚跺地，表示请求发言。一旦得到国王的目光示意，他就跪下，以‘*maeva te ariki*’（欢迎啊，酋长）为开场，开始他的颂辞。说完，起身让给下一个人。”[^t2]

¶11 第二首颂歌开头把家族的血脉比作的不是一条“道路”，而是“一株小树，伸出根须，像 Kofai 树那样蔓延开去”。这里指的是一种开红花和黄花的树；红与黄在整个波利尼西亚都是酋长的神圣颜色，因此用它来象征王族血统十分贴切。接下来是一段迁徙故事，列举了太平洋上的一些著名地方。随后几节讲众神的诞生，措辞过于隐晦，我不敢尝试分析。生长草木的力量被归于 Tane 神。大地“被破开”，人类“出来了”，彩虹受到欢呼。

!!! culture "红与黄：酋长的颜色"
    在夏威夷，最高等级的酋长披用红、黄两色鸟羽织成的羽毛斗篷（‘ahu‘ula）和羽毛头盔；在塔希提，红羽腰带（maro ‘ura）是最高酋长的标志。用一棵开红黄花的树来象征王族，与这一传统相合。夏威夷人也把彩虹看作高等酋长或神灵在场、降生的征兆，所以土阿莫土颂歌中“欢呼彩虹”一句，对夏威夷读者来说并不陌生。

¶12 在颂歌的这一部分，来自四面八方的“发言者”献上他们的“演说”，内容是一串地名。这里被译作“演说”的 *vananga* 一词，与马克萨斯语的 *vanana* 相同，这一相同说明两地这类仪式颂歌的功能有密切联系。[^t3]夏威夷语中指“一个家族的亲属圈子”的 *hanauna* 一词，或许就是它在夏威夷的对应词。至少在我看来，Smith 在这个场合把 *vananga* 译作“演说”，没有译出它的全部含义。《库穆利波》整体的展开，建立在这样一个观念之上：从种族之初确立、并出自原初众神的同一血脉中，代代相传的血缘承续。从 Handy 关于马克萨斯头生子仪式的报告，虽然出色却太过简略，可以公允地推断：这里的关注点同样不在于对世界何以如此安排的任何思辨，而在于颂歌对孩子的直接效力，家族在地上的延续全要指望这个孩子。正如 Handy 所说：“这些颂歌实际上等于精心编排的致效咒语。”

!!! language "vananga、wānanga 与 hanauna"
    Beckwith 把土阿莫土语的 *vananga* 与夏威夷语的 *hanauna*（今写 hanauna，“一代人、同辈亲属”，来自 hānau“生”）联系起来，是为了强调颂歌的谱系性质。按照波利尼西亚语言之间的规则对应，土阿莫土语 *vananga* 更直接的同源词是毛利语的 *wānanga*（秘传的学问、神圣的吟诵；“学问之屋”Whare-wānanga 即由此得名），夏威夷语中与之对应的词形是 *wānana*（今义“预言”）。Beckwith 的推测只能算一种联想。

!!! modern "“致效咒语”与仪式的效力"
    Handy 的“causative spells”一语，带有 20 世纪初人类学把“巫术”与“宗教”对立起来的色彩（Frazer 等人认为巫术是强迫自然，宗教是祈求神灵）。Beckwith 在下一段就表示，这种区分只能就具体情形而论，不能一概而言。今天的研究者多半不再用这种二分法，而是关注颂歌在仪式中“以言行事”的力量：在夏威夷人看来，词语本身有 mana，正确地吟诵谱系就能确立并维系一个人的身份与地位。参见[[essays/genealogy-and-rank]]。

¶13 任何仪式行为中，巫术与宗教崇拜各占几分，是一个因人而异的问题，无法作为一般结论来验证。我自己观察夏威夷人对待他们哪怕是次要神灵的态度，虽然这些观察完全得自基督教传入以后的时代，使我相信：大多数夏威夷人赋予他们的神以人的激情，正如他们在酋长生前给予神的尊荣，死后又把酋长立为神。他们无疑认为，这些灵界的居民不仅能显现为物质形态和自然力量，还能显现在活在地上、生活在人群中的人的身体里。关于众神的颂歌与故事就是这样处理的。因此，整个物质世界都是神显现出来的产物。新生的高等酋长之子，就字面意义而言，生下来就是一位神。吟诵谱系祷歌，不仅是尊崇他所认作亲族的那一长串祖神，也是提醒他们对家族世系中这个新后裔所负的责任。这样，就像为一对慈爱父母的孩子请求那样，为他求得动植物的丰饶，以及人生道路上的顺遂，这些都是他的福祉所必需的，也唯有神才能赐予。

!!! culture "生下来就是神"
    在夏威夷的等级观念中，近亲婚配的两位高等酋长所生的孩子称为 [[g:niaupio|nī‘aupi‘o]]，被视为神（akua），享有臣民须俯伏在地的“俯伏禁忌”（kapu moe）。《库穆利波》据说就是为这样一位王子 Ka-‘I-‘i-mamao 而作的，见[[ku:2]]、[[ku:3]]。Beckwith 所说“吟诵谱系是提醒祖神负起责任”，与夏威夷人对 [[g:aumakua|‘aumakua]]（家族守护神）的态度一致：祖先既是被崇拜的神，也是有义务照看子孙的亲人。参见[[essays/akua-aumakua-kupua]]。

[^t1]: *Vaitu* 与 *tupuranga* 是土阿莫土语。*tupu*“生长”在夏威夷语中对应 *kupu*（发芽、生长），*-ranga* 是名词化后缀；*Vaitu* 的确切含义 Beckwith 只说是“小神”，本站不作推测。
[^t2]: *ariki* 即夏威夷语的 *ali‘i*（酋长）；*maeva* 是塔希提语和土阿莫土语中表示欢迎、致敬的词。*mahora* 指宫廷前的空场，Smith 所据的译者如此解释。
[^t3]: Beckwith 在本章前文（¶2–¶5）引 Handy 时写作 *vavana*，这里写作 *vanana*，原书如此，照录。
