!!! tldr "本文要点"
    - 传统远洋导航要同时解决三件事：保持航向、估计船的位置、在看见陆地之前就知道陆地在哪里。依靠的是星辰的出没方位、太阳、涌浪与风、在脑中持续进行的推算，以及海鸟、云等陆地征兆。
    - 今天通行的“夏威夷星罗盘”把地平线分为 32 间“屋”，是 Nainoa Thompson 在 1970 年代末以后结合密克罗尼西亚航海术、夏威夷语名称和现代天文学重新建立的，不是原样流传下来的古代体系。
    - 纬度靠星的高度判断：北极星 Hōkūpa‘a 的高度约等于所在纬度；大角星 Hōkūle‘a 在夏威夷的纬度上经过天顶。
    - Beckwith 的两本书保存了航海者的传统形象（马卡利伊、基拉、帕卡阿）和一份长长的星名单，但没有关于具体导航方法的系统记载。
    - 所谓用盛水的石碗或葫芦“在水镜中观星”“测纬度”，不见于 19 世纪夏威夷学者的著作，也不见于早期外国人的记录，属于晚出、证据薄弱的说法。

## 导航要解决的三个问题

不用罗盘、六分仪、海图和时钟的导航，英语里常称为 wayfinding。关于波利尼西亚人能否有意远航的争论，以及 Hōkūle‘a 号 1976 年的实验航行，见[[essays/voyaging]]。这里只讲方法本身。

远洋航海者每时每刻都在处理三个问题：

| 问题 | 主要依据 |
|---|---|
| 船头朝向哪里 | 星辰在地平线上的出没方位；日出日落的方位；涌浪与风的方向 |
| 船现在在哪里 | 出发以来的航向、船速与时间（推算）；星辰的高度（纬度） |
| 陆地在哪里 | 傍晚归巢的海鸟；停在岛屿上空的云；被岛屿折射、反射而改变的涌浪；漂浮的植物 |

这些依据没有一项单独可靠：星会被云遮住，风会转向，海鸟会迷路。航海者的本领在于把它们互相印证，并在几周的航程中几乎不眠地保持记忆。

## Beckwith 书中的航海者与星名

《夏威夷神话》没有专讲航海术的章节，但航海者在迁徙传说中处处出现，而且总与星象知识连在一起。

- **马卡利伊（Makali‘i）**：发现者哈瓦伊洛亚（Hawaiiloa）的首席领航员，“精通星象（[[g:kilo-hoku|kilo hoku]]）”。Beckwith 说，按哈瓦伊洛亚传说，他的名字意为“酋长之眼”，指的正是领航员的职守（[[ch:26]]）。
- **帕奥（Paao）的船队**：祭司帕奥本人主持航行中的祭祀，Makaalawa 任“领航员兼天象家”，另有帆船长、号手和四十名划手（[[ch:26]]）。
- **拉阿迈卡希基（La‘a-mai-kahiki）的船队**：随行有他的祭司、一位天象家、一位占卜者、一位先知和一名鼓手（[[ch:25]]）。
- **基拉（Kila）**：一个版本说，莫伊凯哈（Moikeha）亲自教他“航海术与星辰知识”，让他率船去卡希基接拉阿；航行时他的位置在两船之间的高台上（[[ch:25]]）。
- **帕卡阿（Paka‘a）**：凯阿韦努伊阿乌米（Keawe-nui-a-Umi）的宠臣，继承了父亲在酋长身边的首席谋臣、占卜者、司库和领航员之职。他被人排挤失去领航之职后隐居莫洛凯，把全部风雨知识传给儿子，Fornander 的版本中引了几百个风名（[[ch:7]]）。

!!! note "马卡利伊：昴星，也是毕宿五"
    Makali‘i 通常指昴星团，夏威夷的 [[g:makahiki|Makahiki]] 节即以昴星黄昏时升起为始（[[ku:21]]）。但 Beckwith 在[[ch:26]]说，夏威夷人用这位航海者的名字称呼观测中有用的星：不仅昴星团叫“马卡利伊的星群”（na huihui-a-Makali‘i）或“马卡利伊的网”，毕宿五（Aldebaran）也叫 Makali‘i，是哈瓦伊洛亚传统上的“引航星”。另有星名“马卡利伊的舀水瓢”“马卡利伊的妻子们”。同一个名字指几颗不同的星，在夏威夷星名中并不罕见。

《库穆利波》第十四时代在瓦凯亚（Wakea）诞生之后，列出了五十来行“悬在天上”的星名（[[line:1850-1900]]）。Beckwith 依据天文学者 Maud Makemson 的辨认作了括注（[[ku:21]]），其中有几条与航海直接相关：天狼星有好几个名字，Wa 之外，Hikikauelia 是“航海者的天狼星”，Hikikaulonomeha 是“占星者的天狼星”；Na Hiku（“七”）是北斗七星；Humu 是河鼓二（牛郎星）；Puanakau 是参宿七；‘Au‘a 是参宿四。Beckwith 本人对这份名单的解释偏重社会象征：她认为这些星代表 Makahiki 节上献给少年继承人的贡品，并指出夏威夷人说星是以酋长命名的。

| 夏威夷名 | 通常的认定 | 说明 |
|---|---|---|
| Hōkūpa‘a | 北极星 | 字面义“固定的星” |
| Na Hiku | 北斗七星 | “七”，《库穆利波》第 1895 行 |
| Makali‘i | 昴星团（Beckwith 也记作毕宿五） | Makahiki 节、马卡利伊的传说 |
| Hōkūle‘a | 大角星 | 字面义一般解作“欢乐之星”；夏威夷的天顶星 |
| Hikikauelia | 天狼星 | Beckwith 注为“航海者的天狼星” |
| Hōkūloa | 金星（晨星） | 凯佩利诺（Kepelino）说哈瓦伊洛亚返航时以它为向导 |
| Mānaiakalani | 天蝎座 | 毛伊（Maui）鱼钩之名；作为星座名主要见于现代航海教学 |
| Hānaiakamalama | 南十字座 | 现代航海教学中的通行名称 |

许多古代星名今天已难以确认。2015 年出版的 *Nā Inoa Hōkū*（Rubellite Kawena Johnson、John Kaipo Mahelona 与 Clive Ruggles 合著）系统整理了文献中的夏威夷星名，书中对不少名称只能给出几种可能的认定。

## 星罗盘：地平线上的三十二间屋

一颗恒星每夜从地平线上同一个方位升起，在对称的方位落下；它升起的时刻每天提前约四分钟，但方位不变。只要记住几十颗星各自的出没方位，夜里任何时候看见一颗刚升起或将落下的星，就知道了方向。这是星罗盘的基本原理。

Nainoa Thompson 整理的夏威夷星罗盘把地平线一周分为 32 间“屋”（hale），每间约 11.25 度。东、西、南、北各占一间，即 Hikina、Komohana、Hema、‘Ākau；四个象限用风名命名：东北为 Ko‘olau，东南为 Malanai，西南为 Kona，西北为 Ho‘olua。每个象限内有七间屋，从靠近正东或正西的一侧数起，依次为：

| 屋名 | 字面义 | 位置 |
|---|---|---|
| Lā | 太阳 | 最靠近正东、正西 |
| ‘Āina | 陆地 | |
| Noio | 黑玄燕鸥 | |
| Manu | 鸟 | 居象限正中，即东北、东南、西南、西北 |
| Nālani | 天空 | |
| Nā Leo | 声音 | |
| Haka | 空 | 最靠近正北、正南 |

每个屋名在四个象限各出现一次，加上象限名来区分：Manu Ko‘olau 是东北，Manu Ho‘olua 是西北。一颗在 Manu Ko‘olau 升起的星，就在 Manu Ho‘olua 落下。

几个具体的例子：

- 天赤道上的星从正东升起、正西落下。猎户座腰带最西边的一颗（参宿三）几乎正在天赤道上，是天然的“正东”。
- 太阳的出没方位随季节摆动。在夏威夷的纬度上，日出点一年之中在正东偏北、偏南约 25 度的范围内来回移动，大致在两侧的 Lā 与 ‘Āina 两屋之间。
- 星在刚升起或将落下、离地平线不高时才能指示方向；升到半空的星没有用处。所以一颗星只能用一段时间，然后要换用从同一间屋里接着升起的下一颗。

!!! modern "这是一种复兴，不是原样保存"
    1976 年 Hōkūle‘a 号首航塔希提时，导航的是密克罗尼西亚加罗林群岛 Satawal 岛的 Mau Piailug（1932–2010）。他用的是加罗林群岛的星罗盘，方位以星名命名，体系与名称都与上表不同。此后 Nainoa Thompson 在檀香山毕晓普博物馆天文馆里与讲师 Will Kyselka 一起反复研究星空的运行，又随 Mau 出海学习，在 1970 年代末至 1980 年间形成了这套以夏威夷语命名的星罗盘。1980 年，他以此完成了夏威夷—塔希提的往返导航。传统夏威夷人怎样划分地平线、怎样称呼各个方位，史料几乎没有留下记录。

## 星径与星线

在一些太平洋群岛的航海术中，从同一方位先后升起的一串星，构成一条“星径”（star path，David Lewis 在《我们，航海者》中使用的说法）。航海者夜里沿着星径航行：第一颗星升高了，就换成在它下方、同一位置刚刚出现的第二颗。一条星径相当于一整夜的航向。

今天夏威夷的航海教学还把星空分成若干条“星线”，作为记忆星空的骨架。最常讲的是 Ka Iwikuamo‘o（“脊梁”），大致从北极星经北斗一直连到南十字座，纵贯南北；另一条叫 Ke Kā o Makali‘i（“马卡利伊的舀水瓢”），正好与 Beckwith 记下的古星名“马卡利伊的舀水瓢”相呼应。星线的划分与名称是现代教学的组织方式，具体包括哪些星，不同的讲解者略有出入。

## 纬度：天顶星与北极星

星罗盘只告诉航海者方向，不告诉他船在哪里。南北方向的位置，即纬度，可以从星的高度读出。

**天顶星。** 一颗星经过天顶，说明观察者所在的纬度等于这颗星的赤纬。大角星 Hōkūle‘a 的赤纬约为北纬 19 度，夏威夷群岛位于北纬约 19 至 22 度，所以大角星在夏威夷的上空几乎正好经过头顶。这就是 Hōkūle‘a 号取这个名字的原因。南半球的天狼星赤纬约为南纬 17 度，经过塔希提（南纬约 17.5 度）的天顶。在摇晃的船上判断一颗星是否正好在头顶并不容易，所以天顶星总要与别的方法互相印证。

**北极星的高度。** 北极星的高度约等于观察者所在的北纬度数。在夏威夷，它离地平线约 20 度；向南航行时它越来越低，到赤道附近就沉入地平线下。航海者伸直手臂，用手掌和手指的宽度量度星的高度，事先要按自己的手校准。

**南十字座。** 过了赤道，北极星不再可用，就看南十字座。南十字座竖直时，上下两颗星相距约 6 度；在夏威夷的纬度上，下面那颗星到地平线的距离也约为 6 度。两段距离相等，就说明船回到了夏威夷的纬度。

纬度可以读出，经度却没有类似的星象可读。传统的应对办法是“沿纬度航行”：先设法到达目标岛屿的纬度，而且有意停在它的上风一侧（夏威夷的上风是东边），然后顺风沿着这条纬度线航行，直到发现陆地。从夏威夷去塔希提，Hōkūle‘a 号的策略也类似：出发后尽量向东南争取“东移”，因为过了赤道，东南信风会把船往西推；先到塔希提的东边，再顺风折向目标。

## 涌浪、风与推算

**涌浪。** 大洋上的涌浪由远方的风系产生，传播几千公里，方向在几天内相对稳定。夏威夷附近常有三组：东北信风带来的涌浪，冬季来自北太平洋风暴的北涌，以及夏季来自南半球的南涌。它们与船当下所遇的风浪不同，后者随风而变。航海者要在杂乱的海面上分辨出这几组长涌，记住船头与它们的夹角。阴天或星月不见的夜里，他靠身体感受船随不同涌浪的起伏、摇摆来保持航向。据随船者的记述，Mau Piailug 常常躺在船舱里，仅凭船的运动就能察觉航向的偏差。

**风。** 风是动力，也是参照，但风向会变，所以只能在与星、浪对照之后使用。夏威夷人对风的知识极为细密，几乎每一个地区、每一个海湾都有自己的风名。帕卡阿和他的儿子能够一口气唱出各地的风名，在故事中就是航海者本领的标志（[[ch:7]]）。

**推算。** 航海者在脑中持续记录船速、航向和航行的时间，估计已经走了多远，偏离了预定航线多少。这项工作没有书面记录，全靠记忆，所以远航中的航海者几乎不能长时间睡眠。加罗林群岛的航海者用一种称为 etak 的方法：想象一座看不见的参照岛在星罗盘的方位间移动，以此标记航程进度。这一方法怎样在认知上运作，人类学家和认知科学家有过不同的解释。

## 寻找陆地：鸟、云与“扩大的目标”

岛屿很小，海洋很大。航海者不是要准确命中一个点，而是要进入一片可以察觉陆地的范围。

- **海鸟。** 有些海鸟白天出海捕鱼，傍晚飞回陆地栖息。黑玄燕鸥（noio）和白燕鸥（manu-o-Kū）最常被提到。按现代航海者的经验，前者的活动范围在离岸二三十海里以内，后者可达一百海里以上。傍晚看见它们成群朝一个方向飞，陆地就在那边。
- **云。** 岛屿上空常有不随风移动、或在同一处堆积的云；环礁上空的云底有时映出泻湖的淡绿色。
- **涌浪的变化。** 岛屿会反射、折射涌浪，在下风一侧形成特殊的交错波纹。加罗林群岛和马绍尔群岛的航海者以善读这种波纹著称。
- **漂浮物。** 漂来的树枝、椰子、海藻，说明陆地不远。

这些征兆把一个小岛“放大”成一片宽阔的目标；一串彼此相邻的岛屿就构成一道“屏障”。夏威夷群岛东西绵延数百公里，从南方来的船只要到达这道屏障的纬度，几乎总能察觉其中的某一个岛。

!!! warning "金斑鸻的迁徙是否指引了夏威夷的发现"
    太平洋金斑鸻（kōlea）每年秋天从阿拉斯加飞到夏威夷，春天再飞回去，也有个体继续向南飞到社会群岛等地。常有人推测，南方的航海者注意到这种鸟每年朝北飞去、又从北方飞回，因此推断北方有陆地。这是一种合理的推测，但没有传统记载作证据，不应当作史实来讲。

## 航海者的养成

在加罗林群岛，导航是家族世代传承的专门知识。Mau Piailug 幼年时由祖父开始教导，在陆上用石子或珊瑚块摆成一圈，代表各颗星的出没方位，背诵星径、岛屿与海况的口诀，然后随船实地学习。正式的航海者要经过称为 pwo 的入门仪式。Mau 违背了只传本族的惯例，把知识教给了夏威夷人；2007 年，他在 Satawal 岛为 Nainoa Thompson 等几位夏威夷航海者主持了 pwo 仪式。

夏威夷本地的远洋导航传统在接触西方之前或之后不久就已中断，具体方法没有系统的记载留下来。Beckwith 书中保存下来的，是航海者的社会形象：他们是酋长身边世袭的专职人员，与天象家、占卜者并列（[[ch:25]]）；领航员之职可以被人夺走（[[ch:7]]）；父亲把星辰知识传给最器重的儿子（[[ch:25]]）。这说明导航知识在夏威夷同样是被看守、被传授的专门知识，而不是人人都有的本能。

## 卡希基之路：Ke-ala-i-Kahiki

卡霍奥拉韦岛（Kahoolawe）的西端叫 Ke-ala-i-Kahiki，“通往卡希基之路”，它与拉奈岛之间的海峡也以此为名。Beckwith 记载，Tahiti-nui 从塔希提来，就在卡霍奥拉韦岛的“西南端”（Ka-lae-i-Kahiki）登陆（[[ch:26]]）；瓦哈努伊（Waha-nui）的船去卡希基，也取道这里（[[ch:31]]）。毛伊岛 Waihe‘e 也有一处同名的地方，Beckwith 在[[ch:27]]提到过。这个地名本身记录了“向南出发去卡希基”的方向感，其背景见[[essays/voyaging]]。

!!! modern "卡霍奥拉韦岛"
    1941 年以后，卡霍奥拉韦岛长期被美国军方用作轰炸和射击靶场。1976 年起，Protect Kaho‘olawe ‘Ohana 的成员多次登岛抗议，这与 Hōkūle‘a 号首航同属夏威夷文化复兴的标志性事件。1990 年轰炸停止，1994 年岛屿移交夏威夷州，设立保护区，州法规定将来交给受承认的夏威夷原住民主权实体。今天岛上的文化活动中，航海与 Ke-ala-i-Kahiki 的意象占有重要位置。

## “水镜观星”与“航海葫芦”：证据在哪里

关于夏威夷航海，流传很广的一种说法是：古代的观星者在石碗或葫芦中盛水，从水面的倒影中观察星辰；或者，航海者用一只在一定高度钻有一圈小孔的葫芦，盛水至孔的高度作为水平面，从孔中瞄准北极星，以此检查船是否到达预定的纬度。这种器物在通俗读物中有时被称为“星葫芦”或“航海葫芦”，也有人称为 ipu hōkū。

这个说法有多少根据，需要分开来看。

**有记载的：葫芦与天的象征。** 在夏威夷的宇宙观中，葫芦（[[g:ipu|ipu]]）确实与天空和星辰相连。Beckwith 记载的一个创世故事说，帕帕（Papa）生下一只葫芦，瓦凯亚把盖子抛上去成为天空，把种子抛上去成为星星（[[ch:20]]）。一首洛诺的吟诵说：“葫芦就是这个大世界，它的盖子是天空。”（[[ch:3]]）希娜（Hina）的食物葫芦中逃出了月亮和星星（[[ch:15]]）。还有一句俗语说：“马卡利伊的彩虹色葫芦网悬在高处”（[[ch:26]]）。

**有记载的：航海者的葫芦是装风的。** 在传说中，与航海者联系在一起的葫芦是风葫芦。帕卡阿的母亲交给他一只打磨精良的葫芦，里面装着他祖母 Loa 的骨骸，Loa 生前掌管全群岛每一个地区的风；打开葫芦、呼唤风名，就能唤来想要的风（[[ch:7]]）。Beckwith 特别指出，这里的神力来自对祖先遗骨的占有与对神圣名字的背诵，“与寓言无关”。参见[[essays/bones-and-hunakele]]。

**有记载的：水中倒影。** 用一碗水看倒影的做法出现在别的语境中：看对方在水碗中有没有倒影，可以分辨来者是人还是鬼（[[ch:10]]）；皮科伊阿卡阿拉拉（Pikoi-a-ka-alala）看着一盆水里的倒影射中树上的鸟（[[ch:29]]）。这些都与观星无关。

**没有记载的：观星或测纬度的器物。** 就笔者所知，19 世纪的夏威夷学者 Malo、卡马考（Kamakau）、凯佩利诺的著作中都没有这种器物的描述；18、19 世纪之交的外国访客也没有记录夏威夷人用它导航；Beckwith 的两本书同样没有提到。博物馆中也没有被可靠地认定为导航工具的这类葫芦。这个说法主要见于 20 世纪的英文作品，研究传统航海术的著作一般不把它当作可靠的民族志材料。现代的复兴航行也没有采用它。

**实际操作的困难。** 在起伏的独木舟上，碗里的水面不停晃动，难以当作水平面；一只按固定角度钻孔的葫芦只能检验某一个纬度；而北极星的高度用伸直的手臂就能估量，不需要专门的器具。

!!! warning "怎样看待“航海葫芦”"
    不能断言古代夏威夷人从未用过任何类似的东西，但现有证据只能说明：葫芦象征天穹、风葫芦装着掌管风的祖先遗骨，这些观念是有记载的；“盛水观星”“葫芦测纬度”则是晚出的说法，没有早期史料支持。引用时应当注明它的性质，不宜作为传统导航术的史实介绍。

## 今天的航海者

1976 年以后，波利尼西亚航海协会培养了一代又一代的夏威夷航海者，太平洋各地也造起了自己的传统航海船。Hōkūle‘a 号的环球航行（2014–2017）见[[essays/voyaging]]。现代航海教学吸收了天文馆的星空模拟和现代天文学，同时努力恢复夏威夷语的星名与风名，并把 Beckwith 等人整理的传说当作文化资源。传统星学与现代天文学的关系，在夏威夷也是一个公共议题：围绕冒纳凯阿（Mauna Kea）山顶天文台建设的争议，2019 年演变为大规模的抗议活动，争议的核心是这座圣山的土地与管理权，见[[essays/mauna-kea]]。

在夏威夷人的观念中，星辰既是导航的标志，也是祖先与酋长的名字，是《库穆利波》中“悬在天上”的一长串谱系。航海者在夜海上读星，读的既是方位，也是自己的来历。
